# Nischal Dahal Portfolio

This portfolio has been separated into a clean modular static-site structure.

## Structure

```text
portfolio/
├── index.html
├── assets/
│   ├── css/
│   │   └── style.css
│   ├── js/
│   │   └── script.js
│   ├── images/
│   │   ├── portfolio_qr_helper.png
│   │   └── minimalist_qr_code_business_card_design.png
│   └── documents/
│       └── Nischal_Dahal_Updated_Professional_CV.pdf
└── README.md
```

## Edit Guide

- Edit page content in `index.html`.
- Edit layout, colors, spacing, and responsive design in `assets/css/style.css`.
- Edit mobile menu, scroll reveal, and contact form behavior in `assets/js/script.js`.
- Add project screenshots and profile images in `assets/images/`.
- Add updated CV/certificates in `assets/documents/`.

## Social Media Handles

In `index.html`, search for `social-card` and replace the `#` links with your real profile URLs.
